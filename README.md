# Sharique Ansari | Personal Portfolio

A modern, responsive, and highly dynamic personal portfolio designed to showcase my expertise as an **AI Software Engineer and Team Lead**. 

This repository contains the full source code for my interactive resume and project gallery, featuring a premium dark-themed design with custom glassmorphism effects and fluid animations.

## 🌟 Key Features

- **Multi-Page Architecture**: Seamlessly routed Single Page Application (SPA) with dedicated `Home` and `Hire Me` sections.
- **Glassmorphism UI**: Custom-built CSS styling featuring frosted glass effects, gradient accents, and dynamic hover animations.
- **Dynamic Scroll Effects**: The navigation bar and branding intelligently adapt and scale based on user scroll position.
- **Integrated Contact Form**: Securely connected via Formspree, featuring custom file upload support for Job Descriptions.
- **SEO Optimized**: Fully equipped with Meta keywords, Open Graph tags, and Twitter Cards for robust social sharing previews.
- **Automated Deployment**: Configured with GitHub Actions for instant builds and deployment to GitHub Pages.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router (`HashRouter` for GitHub Pages compatibility)
- **Styling**: Vanilla CSS3
- **Icons**: React Icons
- **Form Handling**: Formspree API

## 🚀 Getting Started Locally

If you'd like to run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sharique-ansari/sharique-ansari.github.io.git
   cd sharique-ansari.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
